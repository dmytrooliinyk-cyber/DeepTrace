# Feature to concept map

## Binary helpers

Concepts: bounds checks, byte slices, big-endian and little-endian integers, bit extraction, structure layouts, hexadecimal representation, Shannon entropy.

## Ethernet, IPv4, and transport parsers

Concepts: MAC addresses, EtherTypes, network byte order, variable header lengths, IP identification, flags, fragmentation, TTL, protocol identifiers, ports, sequence numbers, acknowledgments, TCP control flags, datagram lengths, and ICMP message types.

## ARP

Concepts: link-layer and network-layer address mapping, request and reply operations, hardware and protocol address sizes.

## PCAP and flows

Concepts: file magic, endianness detection, timestamp resolution, capture versus wire length, link-layer identifiers, directional five-tuples, and TCP handshake observations.

## DNS

Concepts: transaction IDs, query flags, section counts, labels, resource-record types and classes, TTL, compression pointers, sockets, timeouts, and reply matching.

## Subnet and route commands

Concepts: masks, prefix lengths, network/broadcast boundaries, usable hosts, binary address representation, longest-prefix selection, gateways, interfaces, and next hops.

## Host and process inspection

Concepts: processes and parents, command lines, start times, users, child processes, local and remote socket endpoints, connection states, interfaces, listeners, Linux procfs, and Windows system APIs through psutil.

## File, PE, and ELF inspection

Concepts: file signatures, hashes, timestamps, entropy, little-endian PE structures, `e_lfanew`, machine types, entry points, image bases, sections, R/W/X permissions, ELF class, ELF byte order, ABI, and table offsets.

## Event timeline and findings

Concepts: source-specific parsing, normalized schemas, timestamp ordering, raw-event retention, process and network relationships, deterministic thresholds, evidence indexes, and risk labels.

## Explain mode

Concepts: nibble extraction, binary display, IPv4 IHL word multiplication, fragmentation bits, TCP flag masks, and mapping numeric fields to protocol meaning.
